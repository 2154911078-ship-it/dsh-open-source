# 桌宠需求文档 (Pet Brief)

## 1. 角色定位

- **名称**: 鲨鱼帽小熊 (Shark Hood Bear)
- **类型**: Q版卡通桌宠
- **原型**: 奶油色小熊佩戴灰色鲨鱼头套（自嘲熊风格）
- **性格**: 呆萌、治愈、活泼

## 2. 视觉风格规范

| 项目 | 规范 |
|------|------|
| 风格类型 | 插画风（非像素风） |
| Q版程度 | 2.5头身，头大身小 |
| 描边 | 粗黑描边（约4-6px），统一线宽 |
| 上色 | 平涂，无渐变无阴影 |
| 主色-身体 | 奶油黄 #F5E6B8 |
| 主色-鲨鱼头套 | 灰蓝 #9AA8B5 |
| 辅助色-鲨鱼腹部/嘴内 | 白色 #FFFFFF |
| 辅助色-舌头 | 粉红 #E88B8B |
| 描边色 | 纯黑 #1A1A1A |
| 背景 | 全透明（RGBA） |

## 4. 动作清单与帧位预算

| 动作 | 帧数 | 起始格 | 结束格 | 帧率(fps) | 循环 | 说明 |
|------|------|--------|--------|-----------|------|------|
| idle | 12 | 0 | 11 | 6 | 是 | 待机呼吸+眨眼 |
| walk | 16 | 12 | 27 | 10 | 是 | 行走循环 |
| run | 12 | 28 | 39 | 12 | 是 | 奔跑循环 |
| sleep | 8 | 40 | 47 | 4 | 是 | 休眠+Zzz |
| interact | 12 | 48 | 59 | 8 | 否 | 点击反馈（跳跃挥手） |
| jump_fall | 8 | 60 | 67 | 8 | 否 | 跳跃/下落 |
| 预留 | 4 | 68 | 71 | - | - | 透明预留帧 |
| **合计** | **72** | - | - | - | - | 8列×9行 |

## 5. 技术约束

- 图集规格: 8列 × 9行 = 72格
- 单格尺寸: 256 × 256 px
- 图集总尺寸: 2048 × 2304 px
- 格式: PNG (RGBA 透明背景)
- 空白帧: 透明填充
- 命名: {action}_{frame:03d}_v1.png

## 6. 验收标准

- [ ] 角色轮廓/比例全帧一致，无漂移
- [ ] 配色稳定，帧间无色偏
- [ ] 所有帧背景透明，无白边/脏像素
- [ ] 动作循环自然，首尾衔接流畅
- [ ] 图集格数 ≤ 72，无越界
- [ ] pet.json 帧索引与图集映射一致
- [ ] 缺失动作 fallback 至 idle
