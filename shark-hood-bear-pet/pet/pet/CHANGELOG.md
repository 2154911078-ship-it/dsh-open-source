# 更新日志 (CHANGELOG)

本文件记录鲨鱼帽小熊桌宠的所有版本变更。

格式基于 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/)。

## [1.0.0] - 2026-08-19

### 新增
- 初始版本发布
- 角色设计：奶油色小熊佩戴灰色鲨鱼头套，Q版2.5头身，粗黑描边平涂风格
- 6组基础动作，共68帧动画 + 4帧预留 = 72格图集
  - `idle` 待机（12帧）：呼吸+眨眼循环
  - `walk` 行走（16帧）：4帧步态循环
  - `run` 奔跑（12帧）：快速奔跑循环
  - `sleep` 休眠（8帧）：Zzz渐进休眠动画
  - `interact` 点击反馈（12帧）：惊讶→跳跃挥手→落地
  - `jump_fall` 跳跃下落（8帧）：下蹲→起跳→下落→落地
- 8列×9行标准图集（pet.png），单格256×256px，总尺寸2048×2304px
- 完整 pet.json 配置（动作/帧率/行为/物理参数）
- QA检查图（preview.png），含棋盘透明验证、动作分区标注、帧号
- 需求冻结文档（pet_brief.md）
- 格位映射表（frame_mapping.json）
- 行为逻辑：空闲随机动作、30秒无交互自动休眠、点击反馈、拖拽交互、移动速度切换
- 缺失动作降级策略：fallback 至 idle

### 技术规格
- 图集格式：PNG (RGBA 全透明背景)
- 风格：插画风 / 非像素风 / Q版
- 配色：奶油黄 #F5E6B8 / 灰蓝 #9AA8B5 / 白 #FFFFFF / 粉红 #E88B8B / 黑 #1A1A1A
- 锚点：(128, 230) 角色底部中心

- **主版本号 (MAJOR)**: 不兼容的 API 变更或角色重设计
- **次版本号 (MINOR)**: 向下兼容的功能性新增（新动作、新行为）
- **修订号 (PATCH)**: 向下兼容的问题修正（帧修正、配置调整）
