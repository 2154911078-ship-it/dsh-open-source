# 鲨鱼帽小熊 桌宠 (Shark Hood Bear Desktop Pet)

> 一只戴着灰色鲨鱼头套的奶油色小熊，呆萌治愈系桌宠

## 角色简介

奶油色小熊佩戴灰色鲨鱼头套，鲨鱼嘴部张开露出小熊呆萌的笑脸。粗黑描边、平涂配色、Q版2.5头身比例，整体风格可爱治愈。

## 使用方法

### 导入 hatchpet

1. 将整个 `pet/` 目录放入 hatchpet 的 pets 文件夹
2. 在 hatchpet 配置中引用 `pet.json`
3. 桌宠将以 `idle` 动作启动

### 行为逻辑

- **默认状态**: `idle`（待机呼吸眨眼）
- **长时间无交互** (30秒): 自动进入 `sleep`
- **空闲随机行为**: 70% idle / 15% sleep / 15% walk
- **点击**: 触发 `interact`（跳跃挥手反馈），冷却500ms
- **拖拽**: 开始时触发 `interact`，释放时触发 `jump_fall`
- **移动**: 慢速播放 `walk`，快速播放 `run`
- **缺失动作降级**: 自动 fallback 至 `idle`
